# BloomKite

Provides real-time analytics for lightweight DeFi dashboards that track swaps and liquidity pools in real time.

BloomKite is built to be simple and practical, focusing on doing one thing well.

**Why BloomKite?**

- and liquidity pools in real

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/BloomKite.git`
2. `cd BloomKite`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
